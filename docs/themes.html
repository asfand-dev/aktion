Theming

Themes are CSS custom properties applied to the host element. The shadow DOM inherits them, so changing a theme is instant — no re-render required. Built-in themes additionally set data-rui-theme="<name>" on the host so the bundled stylesheet can layer on theme-specific tweaks (fonts, gradients, animations) that go beyond the raw token map.

Built-in themes

Seven themes ship out of the box. Pass the name via the theme attribute or call setTheme(). 

<streaming-ui-script theme="light"></streaming-ui-script>     <!-- crisp default      -->
<streaming-ui-script theme="dark"></streaming-ui-script>      <!-- standard dark      -->
<streaming-ui-script theme="neon"></streaming-ui-script>      <!-- cyberpunk glow     -->
<streaming-ui-script theme="pastel"></streaming-ui-script>    <!-- soft & rounded     -->
<streaming-ui-script theme="glass"></streaming-ui-script>     <!-- frosted glass      -->
<streaming-ui-script theme="brutalist"></streaming-ui-script> <!-- neo-brutalism       -->
<streaming-ui-script theme="skyline"></streaming-ui-script>   <!-- enterprise console  -->

Custom token map

Pass a JSON token map directly to the theme attribute or via setTheme():

const el = document.querySelector("streaming-ui-script");
el.setTheme({
  colorPrimary: "#16a34a",
  colorPrimaryHover: "#15803d",
  colorBg: "#f0fdf4",
  radiusMd: "14px",
});

Tip

You can also style the host element from outside (e.g. streaming-ui-script { --rui-color-primary: #16a34a; }). The shadow DOM still uses these variables.

Aligning the background with your page

By default the host element fills its background with the theme's colorBg token. When you embed the component inside a page that already has its own background, that produces a visible seam. There are three ways to fix it — pick whichever fits your stack:

1. Use the transparent attribute

The simplest option: tell the component to skip painting its own background. The internal cards keep their surface colors, so the UI stays legible on any backdrop. 

<div class="my-themed-page">
  <streaming-ui-script theme="dark" transparent></streaming-ui-script>
</div>

2. Override the host background CSS variable

For finer control set --rui-host-bg on the host. It takes precedence over the theme's default background. 

streaming-ui-script {
  --rui-host-bg: transparent;          /* or any color/gradient */
}

3. Match the outer container to the theme's colorBg

Drop the same color on the wrapping container so they blend visually. Useful when you do want the host to keep its background but want the edges to disappear into the page chrome. 

.my-themed-page {
  background: var(--rui-color-bg, #ffffff);   /* mirror the theme */
}

Programmatically you can read the resolved tokens from builtInThemes[name] and apply them to your own container.
