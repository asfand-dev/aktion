Theming

Themes are CSS custom properties applied to the host element. The shadow DOM inherits them, so changing a theme is instant — no re-render required. Built-in themes additionally set data-rui-theme="<name>" on the host so the bundled stylesheet can layer on theme-specific tweaks (fonts, gradients, animations) that go beyond the raw token map.

Built-in themes

Four themes ship out of the box. Pass the name via the theme attribute or call setTheme(). 

<llm-response-ui-lang theme="light"></llm-response-ui-lang>   <!-- crisp default -->
<llm-response-ui-lang theme="dark"></llm-response-ui-lang>    <!-- standard dark    -->
<llm-response-ui-lang theme="neon"></llm-response-ui-lang>    <!-- cyberpunk glow   -->
<llm-response-ui-lang theme="pastel"></llm-response-ui-lang>  <!-- soft & rounded   -->

Want to try them on a richer surface? Open the theme customization studio for a live editor that lets you tweak any token and copy the resulting JSON.

Custom token map

Pass a JSON token map directly to the theme attribute or via setTheme():

const el = document.querySelector("llm-response-ui-lang");
el.setTheme({
  colorPrimary: "#16a34a",
  colorPrimaryHover: "#15803d",
  colorBg: "#f0fdf4",
  radiusMd: "14px",
});

Tip

You can also style the host element from outside (e.g. llm-response-ui-lang { --rui-color-primary: #16a34a; }). The shadow DOM still uses these variables.
