A full analytics surface — DataGrid, Heatmap, Radar, Scatter, Histogram, Gauge, Area

One workspace that puts every new data primitive to work: a sortable, paginated DataGrid with bulk-action toolbar, a Gauge for SLA, an AreaChart for trend, a Heatmap for activity-by-hour, a RadarChart for vendor comparison, a ScatterChart for cohort behaviour, a Histogram for response times, plus an InfiniteList activity feed and an AuditTrail.

What's powerful here

DataGrid ships with a sticky header, sortable columns, per-column filter chips, row selection (the toolbar renders only when @Count($$selectedIds) > 0), and built-in pagination via $$page. The six charts share the same Series([...]) grammar — swap in a Query() result and they all redraw. The Gauge, Heatmap, RadarChart, ScatterChart, Histogram, and AreaChart are all SVG primitives so they print cleanly and stay sharp on retina.
