CalendarView, OnboardingChecklist, InboxPanel, ActivityLog & state cards

A planning workspace that combines a full-month CalendarView with an OnboardingChecklist, an unread InboxPanel, an ActivityLog, and three state primitives (LoadingState / ErrorState / SuccessState). Switching the active state on the toolbar swaps the right pane — no JS, just a @Switch.

Live preview

Click a day in the calendar to focus it. Toggle the right-pane view via the segmented control. Mark onboarding tasks done and watch the count update.

What's powerful here

CalendarView renders a full month grid with per-day event chips, navigation arrows, and a selected-day callback — perfect when DatePicker's single input isn't enough. OnboardingChecklist keeps the completion count in sync with a $$persistent array, so refreshing the page preserves progress. The three state primitives (LoadingState / ErrorState / SuccessState) drop in wherever you'd previously hand-roll an empty Card with grey text.
