Theme customization

Pick one of the four built-in themes, then tweak any token in the side panel — the preview re-renders instantly. Copy the JSON or the setTheme() snippet at the bottom and drop it into your own app.

How theming works

Every theme is just a CSS custom-property map applied to the host element. Built-in themes additionally set data-rui-theme="<name>" so the bundled stylesheet can layer on theme-specific overrides (fonts, gradients, animations). Pass a JSON map to theme or call el.setTheme({...}) for a fully custom palette.

Three ways to apply a theme

      
Pick whichever fits your stack — they all hit the same code path.



// 1. Built-in name on the attribute
<llm-response-ui-lang theme="neon"></llm-response-ui-lang>

// 2. JSON token map on the attribute (escape the quotes)
<llm-response-ui-lang theme='{"colorPrimary":"#16a34a","radiusMd":"14px"}'></llm-response-ui-lang>

// 3. Programmatic — extend a built-in or pass a partial map
const el = document.querySelector("llm-response-ui-lang");
el.setTheme({ colorPrimary: "#16a34a", radiusMd: "14px" });


      
Tips

      
    
        
  • Partial maps are merged on top of the light theme — only override what you need.
    • 
        
  • Switching themes does not re-render: the runtime updates CSS variables on the host element, and the shadow DOM picks them up instantly.
    • 
        
  • You can target the host from outside too: llm-response-ui-lang { --rui-color-primary: #16a34a; }.
