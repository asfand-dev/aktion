Render LLM-generated UI in any framework

<llm-response-ui-lang> is a single web component that turns LLM Response UI Lang text into a rich, interactive UI inside its shadow DOM. It works with any framework — React, Vue, Angular, Svelte, or plain HTML — and ships as a single JavaScript file plus an auto-generated system prompt.

Drop-in CDN install

One script tag and you're rendering generative UI from your LLM.

<script type="module" src="https://asfand-dev.github.io/llm-response-ui-lang/dist/llm-response-ui-lang.js"></script>
<llm-response-ui-lang theme="light"></llm-response-ui-lang>
<script>
  const el = document.querySelector("llm-response-ui-lang");
  el.setResponse(`root = Stack([greeting])
greeting = Card([CardHeader("Hello", "Generative UI in plain HTML")])`);
</script>

Framework-agnostic

Built on the standard Custom Elements API — works wherever HTML works.

LLM Response UI Lang

Parser, evaluator, reactive state, queries, mutations, and built-in functions.

Streaming-first

Use appendChunk() to feed LLM tokens as they arrive.

Theming

Switch themes via the theme attribute or pass a JSON token map.

System prompt included

Use the auto-generated system_prompt.txt or call getSystemPrompt().

Extensible

Register your own components via registerComponents([...]).

Live demo

The component below was rendered from a few lines of LLM Response UI Lang. Use the theme picker to swap palettes — the preview updates instantly.

Welcome card with chart

root = Stack([welcome, kpis, chart, follow])
welcome = Card([
  CardHeader("Hello there", "Generative UI rendered from LLM Response UI Lang"),
  Markdown("This card was streamed in **plain text** and rendered as a real UI.")
])
kpis = Stack([
  StatCard("Active users", "12,540", "up", "+18% vs last week"),
  StatCard("Revenue", "$48.2k", "flat", "0% vs last week"),
  StatCard("Errors", "12", "down", "-32% vs last week")
], "row", "m", "stretch", "start", true)
chart = Card([
  CardHeader("Daily traffic"),
  LineChart(["Mon","Tue","Wed","Thu","Fri","Sat","Sun"], [
    Series("Visits",[120,180,160,210,250,200,230]),
    Series("Signups",[12,18,15,22,28,21,24])
  ])
])
follow = FollowUpBlock([
  FollowUpItem("Show conversion funnel"),
  FollowUpItem("Compare to last month"),
  FollowUpItem("Send report by email")
], "Try one of these")
