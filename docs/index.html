Introduction

Aktion.

Aktion is a compact declarative language — a strict subset of JavaScript — for building rich UIs, whether an LLM writes them token‑by‑token or you write them by hand. A program is a handful of bindings ending in aktion = …; the <aktion-app> web component renders it live, in its own shadow DOM, the moment it streams in. No build step, no JSX, no flexbox bookkeeping — just composition that runs anywhere HTML runs.

Why Aktion

  • Declarative. Describe the UI as a tree of data; the runtime handles the DOM, layout, and updates.
  • Batteries included. Around 130 components — layout, forms, charts, tables, and full patterns like dashboards and app shells.
  • Reactive. One sigil, $state. Read it in your tree, write it in a function, and the UI re‑renders itself.
  • Streaming‑friendly. The language is line‑oriented and error‑tolerant, so an LLM’s tokens render top‑down as they arrive.
  • Themeable. Switch palettes with the theme attribute or override tokens in‑script with $theme({…}).
  • Runs anywhere. A standard custom element — drop it into React, Vue, Angular, Svelte, or plain HTML.

A taste of the language

State is the one piece of magic. Declare a reactive value with the $ sigil, read it anywhere in your tree, and mutate it inside a function — the UI updates on its own. Click the button:

Live 
$count = 0
function inc() { $count = $count + 1 }
aktion = Card([
  CardHeader("Reactive counter"),
  Text(`You clicked ${$count} times.`, { variant: "large-heavy" }),
  Button("Increment", { variant: "primary", icon: "plus", onClick: inc })
])

Layout is composition. Column stacks vertically (the usual page root), Row lays out left‑to‑right at natural widths, and Grid builds equal columns and reflowing card walls — no CSS required.

Live 
aktion = Column([
  Row([Text("Inbox", { variant: "large-heavy" }), Spacer(), Button("Compose", { variant: "primary", icon: "plus" })], { gap: "s" }),
  Grid([
    Card([CardHeader("Tile A")]),
    Card([CardHeader("Tile B")]),
    Card([CardHeader("Tile C")])
  ], { columns: 3, gap: "m" })
], { gap: "l" })

Data comes from $http({ url, … }) — a reactive resource with .data, .error, .loading, and .refetch(). Pair it with Async(resource, { loading, error, empty, data }) to branch on its state — one of the four slots renders depending on whether the request is loading, failed, empty, or done. Here we hand it a resolved resource so the data branch shows:

Live 
$users = [{ name: "Ada Lovelace" }, { name: "Alan Turing" }, { name: "Grace Hopper" }]
aktion = Card([
  CardHeader("Users"),
  Async({ state: "data", data: $users, loading: false }, {
    loading: Skeleton("paragraph", { count: 3 }),
    error: Callout("danger", { title: "Load failed" }),
    empty: EmptyState("No users yet"),
    data: Column($users.map(u => Text(u.name)))
  })
])

What’s new

  • Layout primitives. Column / Row / Center plus Grid with GridItem 12‑track spans replace hand‑rolled flexbox. Read the layout guide →
  • Timers. setTimeout / setInterval (and their clear… partners) work just like in the browser and are torn down with the program. JavaScript interactions →
  • $http(…).onDone. Fire a callback when a request settles — ideal for refetching a list after a save. See actions →
  • Full JavaScript global surface. alert, confirm, prompt, fetch, crypto, navigator, Intl, JSON, Math, and friends are all available inside action and effect bodies. Learn more →
  • Render‑anything table cells. Table and DataGrid columns take a render prop to drop any component — a Badge, a Button — into a cell, or an onClick to make a whole column clickable. Browse components →
