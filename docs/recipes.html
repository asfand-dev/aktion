Recipes, patterns & anti-patterns.

Aktion ships a cookbook of 22 application patterns (A–V) plus a strict do/don’t table. This page surfaces them for human readers, organised by the task you’re trying to accomplish, with a self-check to run before you ship.

JS-aligned do / don’t

Aktion is a strict subset of JavaScript. Use these shapes and avoid their legacy equivalents:

Use thisWhy
$app(Stack([...]))The canonical entry point — first line of every program. (The legacy aktion = … binding is gone.)
$x = 0One reactive-atom kind. No declaration keyword.
function User(u) { return Card([...]) }PascalCase function = component; must return its tree.
function save() { ... }camelCase function = action.
Button("Save", { variant: "primary" })One positional arg max; named props go in a trailing object. Multi-positional calls raise a schema error.
items.map(x => ...) / cond ? a : bStandard JS iteration and ternaries in expression position.
switch (v) { case "a": return X; default: return Y }Standard JS switch (no DSL match).
$effect(() => { ... }, [$x])Callback + deps array.
$emit("name", { detail })Function-call syntax for events.
$toast.show(...)Use the toast manager — don’t hand-manage a $toasts = [...] array.
// comment or /* … */Only the two JS comment forms.
Font Awesome names ("heart")No emoji in icon: slots; no fa- prefix.
tone: / variant: / theme tokensNo hard-coded colours or gradients.

Self-check before you ship

Walk your program and confirm:

  1. $app(...) is the first line.
  2. Every referenced name is defined somewhere.
  3. Every defined name (other than the $app(...) root and theme) is reachable from the root.
  4. Containers reference their children by name; large data arrays live on their own trailing lines.
  5. Components (PascalCase) end with an explicit return.
  6. Actions (camelCase) use the function keyword.
  7. State uses the single-sigil $name = value form.
  8. HTTP uses $http({ url, method, ... }) with an absolute URL; reads that need caching use $query({...}), deferred writes use $mutation({...}), toasts go through $toast.
  9. Router uses $router({...}) and the route surface is route.*.
  10. Effects use $effect(() => { ... }, [deps]).
  11. Named arguments are wrapped in an object.
  12. Every visible button is wired to a function or lambda.
  13. Icons are Font Awesome names (no emoji).
  14. No hard-coded colours; styling uses tone: / variant: / theme tokens.
  15. One positional argument max per component call.
  16. $emit("name", detail) uses function-call syntax.
