      The one-scroll cheat sheet

      The two rules

      $name = valueThe $ sigil makes state reactive. That's the only magic.
      Comp(arg, { props })Trailing-object rule: max one positional arg, everything else in one {}.

      Builtins

      $app(tree)Mount the UI. One per program.
      $effect(fn, deps)Side effects: [$atom, "mount", "every(1000)", "debounce(300)"]
      $http({ url })Reactive resource: .data .loading .error .refetch()
      $form({...})Values, rules, submit, errors, touched — the whole form ceremony.
      $router({...})Hash routing + NavLink + route.params/navigate
      $theme({...})7 built-in themes, 80+ tokens, brand from inside the script.
      $toast.success()Notifications without hand-rolling a toast array.
      $store({...})Shared state + persist + history: true (undo/redo).
      $storage.set/getlocalStorage / session / cookies, no imports.
      $util.*filter, sort, groupBy, formatDate, rules.* — lodash's cooler cousin.
      $emit("evt", {...})Dispatch a CustomEvent to the host page.
      $i18n({...})Translations with t(key) + language switching.

      Styling

      sx: { p:"l", bg:"gradient.brand" }Token-aware styles on any component.
      states: { hover: {...} }Interaction states compiled to scoped CSS.
      animate: "fade-up"Motion presets, one prop.
      { base:"1", md:"2" }Any sx value accepts a responsive map.
