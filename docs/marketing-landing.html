A full marketing landing page, generated from one Streaming UI Script program

No Query, no Mutation — just composable patterns. Hero with CTAs and highlights, feature grid, testimonials, pricing tiers, team line-up, and a closing banner. The same UI Script program would scale to any LLM-authored landing page or product announcement.

What's powerful here

This landing page is 70 lines of Streaming UI Script. No CSS, no JavaScript, no host wiring — just one setResponse(…) call and the patterns do the rest. 

// Host code is one line:
el.setResponse(document.getElementById("src-landing").textContent);
