Connect to OpenAI

This demo sends your messages to the OpenAI Chat Completions API. The assistant is instructed to respond only in LLM Response UI Lang, which is then rendered inline by <llm-response-ui-lang>.

Stored locally in your browser. Never sent anywhere except OpenAI.
Any chat-completion model your key has access to.

Your key stays in localStorage on this device only. Clear it any time via the “Reset” button in the chat header.
