The pitch

Stop wiring twelve libraries together. Write one language instead.

A modern React app is a framework, plus a router, plus a state library, plus a forms library, plus a component kit, plus an i18n package, plus a data layer, plus a bundler config to glue it all. Aktion folds all of that into a single reactive language and one runtime atom — so the whole surface area you have to learn (and maintain) collapses.

LLM-native by design

ReactCounter.jsx
import { useState } from "react";

export function Counter() {
  const [count, setCount] = useState(0);
  return (
    <div className="card">
      <h3>Reactive counter</h3>
      <p>You clicked {count} times.</p>
      <button onClick={() => setCount(count + 1)}>
        Increment
      </button>
    </div>
  );
}
Aktionapp.aktion
$count = 0
function inc() { $count = $count + 1 }

$app(Card([
  CardHeader("Reactive counter"),
  Text(`You clicked ${$count} times.`),
  Button("Increment", { onClick: inc })
]))
ReactUsers.jsx
function Users() {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    fetch("/api/users")
      .then((r) => r.json())
      .then(setData)
      .catch(setError)
      .finally(() => setLoading(false));
  }, []);

  if (loading) return <Spinner />;
  if (error) return <Error />;
  return <ul>{data.map((u) => <li>{u.name}</li>)}</ul>;
}
Aktionapp.aktion
$users = $http({ url: "/api/users" })

$app(Async($users, {
  loading: Skeleton("paragraph", { count: 3 }),
  error: Callout("danger", { title: "Load failed" }),
  data: Column($users.data.map(u => Text(u.name)))
}))

LLM-first

The language models already speak fluently

Because the grammar is small, regular, and a strict subset of JavaScript, models generate it correctly — and because it streams, what they generate renders as it's typed.

  • Tokens render top-down. The parser commits each line to the DOM the instant it arrives — no waiting for a closing brace.
  • Error-tolerant. A half-finished statement won't blow up the page — it simply renders when complete.
  • A generated system prompt. Ship the model the full grammar and component catalog in one call to getSystemPrompt().
  • Not just chat. Generative UI is one use case — Aktion is a complete app language whether a human or a model writes it.
