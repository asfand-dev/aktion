# `$`-builtins

All 26 builtins the runtime dispatches. A `$`-prefixed callee that
is not in this list is **not** a builtin — it is either one of your own hooks
(`function $useThing()`) or a mistake.

The `$` sigil is what makes a binding reactive. `$name = value` declares a reactive atom;
reassigning it re-renders the parts of the tree that read it.

## hook

Per-instance state, mirroring React's `useState` / `useMemo` / `useRef` / `useReducer` / `useId`.

### `$state`

```
$state(initial)
```

Hook: per-instance state → [value, setValue] (like React's useState).

### `$memo`

```
$memo(() => value, [deps])
```

Hook: value recomputed only when a dependency changes (like useMemo).

### `$ref`

```
$ref(initial)
```

Hook: stable { current } box; writing .current does not re-render (like useRef).

### `$reducer`

```
$reducer((state, action) => next, initial)
```

Hook: [state, dispatch] (like useReducer).

### `$id`

```
$id(prefix?)
```

Hook: stable unique id per component instance (like useId).

## effect

Side effects, transactions, global stores, and managed forms.

### `$effect`

```
$effect(() => { … }, [deps])
```

Declarative side effect; deps mix $state, "mount"/"unmount", "every(N)", "debounce(N)".

### `$optimistic`

```
$optimistic(() => { … })
```

Run optimistic writes; auto-rolls back state if the callback throws or rejects.

### `$store`

```
$store({ ...state, ...methods })
```

Global store: shared state + actions (like Zustand/Pinia). persist: "key" mirrors data to localStorage (persistIn: "session" for sessionStorage); history: true|depth adds undo()/redo()/clearHistory() + reactive canUndo/canRedo.

**Config keys** — the only keys `$store({ … })` accepts:

| key | type | notes |
| --- | --- | --- |
| `persist` | `string` | Mirror the store's data to localStorage under this key (hydrates on first render). |
| `persistIn` | `enum: "local" \| "session"` | Storage backend for `persist` (defaults to local). |
| `history` | `boolean \| number` | Enable undo()/redo()/clearHistory() + reactive canUndo/canRedo (number = depth). |

### `$form`

```
$form({ values, rules, onSubmit })
```

Reactive form engine: values/errors/touched/dirty/valid/submitting/validating + field()/validate()/touch()/setField()/submit() (alias handleSubmit())/reset(). Async rules ($util.rules.asyncCustom) are awaited before submit; submitting stays true until an async onSubmit settles.

**Config keys** — the only keys `$form({ … })` accepts:

| key | type | notes |
| --- | --- | --- |
| `values` | `object` | Initial field values — the clean snapshot. |
| `rules` | `object` | Per-field validator arrays: { field: [$util.rules.required(), …] }. |
| `onSubmit` | `(values) => void` | Called with the values once validation passes. |

## data

Data resources. Each returns a **reactive bag** — see `namespaces.md` for its members.

### `$http`

```
$http({ url, method, … })
```

Reactive HTTP resource bag — { data, loading, error, refetch }.

**Config keys** — the only keys `$http({ … })` accepts:

| key | type | notes |
| --- | --- | --- |
| `url` | `string` | Absolute request URL. |
| `method` | `enum: "GET" \| "POST" \| "PUT" \| "PATCH" \| "DELETE" \| "HEAD" \| "OPTIONS"` | HTTP method. Defaults to GET. |
| `query` | `object` | Object serialised into the URL querystring (`?k=v`). |
| `headers` | `object` | Request headers as a plain object. |
| `body` | `object` | Request body. Objects are JSON-encoded automatically. |
| `credentials` | `enum: "omit" \| "same-origin" \| "include"` | Fetch credentials mode. |
| `mode` | `enum: "cors" \| "no-cors" \| "same-origin"` | Fetch request mode. |
| `cache` | `enum: "default" \| "no-store" \| "reload" \| "no-cache" \| "force-cache"` | Fetch cache mode. |
| `gql` | `string` | GraphQL query — POSTs { query, variables }; `.data` is the unwrapped GraphQL data. |
| `variables` | `object` | GraphQL variables paired with `gql`. |

### `$query`

```
$query({ url, key, ttl })
```

Cached + deduplicated HTTP read. Polling via refetchInterval/refetchOnFocus/refetchOnReconnect; pagination via infinite: { param, limit, mode } (→ .loadMore()/.hasMore/.loadingMore); GraphQL via gql + variables.

**Config keys** — the only keys `$query({ … })` accepts:

| key | type | notes |
| --- | --- | --- |
| `url` | `string` | Absolute request URL. |
| `method` | `enum: "GET" \| "POST" \| "PUT" \| "PATCH" \| "DELETE" \| "HEAD" \| "OPTIONS"` | HTTP method. Defaults to GET. |
| `query` | `object` | Object serialised into the URL querystring (`?k=v`). |
| `headers` | `object` | Request headers as a plain object. |
| `body` | `object` | Request body. Objects are JSON-encoded automatically. |
| `credentials` | `enum: "omit" \| "same-origin" \| "include"` | Fetch credentials mode. |
| `mode` | `enum: "cors" \| "no-cors" \| "same-origin"` | Fetch request mode. |
| `cache` | `enum: "default" \| "no-store" \| "reload" \| "no-cache" \| "force-cache"` | Fetch cache mode. |
| `gql` | `string` | GraphQL query — POSTs { query, variables }; `.data` is the unwrapped GraphQL data. |
| `variables` | `object` | GraphQL variables paired with `gql`. |
| `key` | `string` | Cache key — identical keys share one in-flight request + cached bag. |
| `ttl` | `number` | Milliseconds before cached data is considered stale and auto-refetched. |
| `refetchInterval` | `number` | Poll interval in ms (live dashboards). |
| `refetchOnFocus` | `boolean` | Refetch when the tab regains focus. |
| `refetchOnReconnect` | `boolean` | Refetch when the network reconnects. |
| `infinite` | `object` | Pagination config: { param?, start?, limit?, mode?, select? } → .loadMore()/.hasMore. |

### `$mutation`

```
$mutation({ url, method })
```

Deferred write; fires on .mutate(overrides?). optimistic: (vars) => {…} applies instantly (auto-rollback on failure); invalidates: [keys] refetches matching cached queries; gql for GraphQL.

**Config keys** — the only keys `$mutation({ … })` accepts:

| key | type | notes |
| --- | --- | --- |
| `url` | `string` | Absolute request URL. |
| `method` | `enum: "POST" \| "PUT" \| "PATCH" \| "DELETE"` | HTTP method. Defaults to POST. |
| `body` | `object` | Default body; shallow-merged with `.mutate(overrides)`. |
| `headers` | `object` | Request headers as a plain object. |
| `query` | `object` | Object serialised into the URL querystring. |
| `optimistic` | `(vars) => void` | Runs synchronously before the request; auto-rolled-back on failure. |
| `invalidates` | `string[]` | Refetch every cached $query whose key contains a listed substring on success. |
| `gql` | `string` | GraphQL mutation document. |
| `variables` | `object` | GraphQL variables paired with `gql`. |

### `$socket`

```
$socket({ url, reconnect? })
```

Reactive WebSocket — { status: "connecting"|"open"|"closed", connected, last, messages, attempts, send, close }. reconnect: true|n retries with exponential backoff; sends queue while connecting and flush on open; close() stops for good.

**Config keys** — the only keys `$socket({ … })` accepts:

| key | type | notes |
| --- | --- | --- |
| `url` | `string` | WebSocket URL (ws:// or wss://). |
| `protocols` | `string \| string[]` | Optional sub-protocol(s). |
| `bufferSize` | `number` | Max buffered messages kept in `.messages`. |
| `onMessage` | `(msg) => void` | Callback fired for each received message. |
| `reconnect` | `boolean \| number` | Retry dropped connections (true, or a max-attempt count) with backoff. |

### `$sse`

```
$sse({ url, event })
```

Reactive Server-Sent Events stream — { status, connected, last, messages, close }. EventSource reconnects natively (status reads "connecting" while it does).

**Config keys** — the only keys `$sse({ … })` accepts:

| key | type | notes |
| --- | --- | --- |
| `url` | `string` | EventSource URL. |
| `event` | `string` | Named event to listen for (defaults to message). |
| `withCredentials` | `boolean` | Send credentials with the EventSource request. |
| `bufferSize` | `number` | Max buffered events kept in `.messages`. |

### `$script`

```
$script({ src, global? })
```

Load an external UMD/ESM script or stylesheet once → reactive { ready, loading, error, value }. `global` reads window[global] into `value` (e.g. window.Stripe). De-duplicated per src across the app; gate a third-party widget on `.ready`.

**Config keys** — the only keys `$script({ … })` accepts:

| key | type | notes |
| --- | --- | --- |
| `src` | `string` | URL of the script (or stylesheet) to load. De-duplicated per src. |
| `global` | `string` | Name of the window global the script defines — read into `.value` once ready (e.g. "Stripe"). |
| `type` | `string` | Script type attribute (e.g. "module" for ESM). |
| `as` | `enum: "script" \| "style"` | Force the resource kind. Inferred from a `.css` src otherwise. |
| `attributes` | `object` | Extra attributes to set on the injected <script>/<link> (e.g. crossorigin, integrity). |

### `$i18n`

```
$i18n({ translations, … })
```

Translation bundle → { t, setCurrentLanguage, getCurrentLanguage }.

**Config keys** — the only keys `$i18n({ … })` accepts:

| key | type | notes |
| --- | --- | --- |
| `defaultLanguage` | `string` | Fallback language when a key is missing for the current language. |
| `currentLanguage` | `string` | Active language — drive from a reactive atom for live switching. |
| `translations` | `object` | { key: { lang: "text {name}" } }. Supports ICU plural/select. |

## app

Application-level declarations.

### `$head`

```
$head({ title, meta, og, twitter, link, jsonLd })
```

Reactive document head: title, meta description, canonical/alternate links, Open Graph + Twitter cards, JSON-LD, <html> attrs. Per-route calls compose; renderToString emits the resolved <head> so SSR pages are crawlable.

**Config keys** — the only keys `$head({ … })` accepts:

| key | type | notes |
| --- | --- | --- |
| `title` | `string` | Document title (sets document.title + <title>). |
| `titleTemplate` | `string` | Wrap `title` with a template, e.g. "%s — Acme". |
| `meta` | `object` | Named meta tags: { description, "theme-color", keywords, … } → <meta name content>. |
| `og` | `object` | Open Graph tags: { title, image, type, … } → <meta property="og:KEY">. |
| `twitter` | `object` | Twitter card tags: { card, site, … } → <meta name="twitter:KEY">. |
| `link` | `object[]` | Array of <link> descriptors, e.g. [{ rel: "canonical", href }]. |
| `jsonLd` | `object \| object[]` | JSON-LD structured data → <script type="application/ld+json">. @context defaults to schema.org. |
| `base` | `string \| object` | <base href> for the document. |
| `htmlAttrs` | `object` | Attributes for the <html> element, e.g. { lang: "en", dir: "ltr" }. |

### `$app`

```
$app(root)
```

Register the root of the rendered UI tree — every program needs one.

## routing

Client-side routing.

### `$router`

```
$router({ '/': Home(), default: NotFound() })
```

Outlet-first router: maps path patterns to component trees.

## theme

Design tokens.

### `$theme`

```
$theme({ colors, radius, font, … })
```

In-script theme override merged on top of the active base theme. Structured groups: colors/radius/font/spacing/shadows/gradients/zIndex/motion/fonts (web-font import)/icons (custom inline SVG), plus name/direction metadata.

**Config keys** — the only keys `$theme({ … })` accepts:

| key | type | notes |
| --- | --- | --- |
| `name` | `string` | Selects a built-in base theme ("light", "dark", "shadcn"/"-light"/"-dark", "mui"/"-light"/"-dark", "heroui"/"-light"/"-dark", "soft"). |
| `direction` | `enum: "ltr" \| "rtl"` | Reading direction (metadata). |
| `colors` | `object` | CSS color tokens: bg, surface, border, text, primary, accent, success, warning, danger, info, …. |
| `radius` | `object` | Border-radius tokens: xs, sm, md, lg, pill, button, input. |
| `font` | `object` | Font tokens: family, familyHeading, familyMono, sizeBase, weightBody, …. |
| `spacing` | `object` | Spacing scale tokens. |
| `shadows` | `object` | Box-shadow tokens. |
| `gradients` | `object` | Gradient color-stop arrays — referenced as gradient.<name>. |
| `zIndex` | `object` | Layer tokens (modal, toast, …) → sx.zIndex / --rui-z-*. |
| `motion` | `object` | Motion tokens: { fast, base, slow, ease } → --rui-motion-*. |
| `fonts` | `object` | Web-font import: { import: ["Inter:400,700"] }. |
| `icons` | `object` | Custom inline-SVG icons by name, usable anywhere an icon name is. |

## event

Escaping to the host page.

### `$emit`

```
$emit('name', detail)
```

Dispatch a CustomEvent from the host element.

## namespace

Reserved namespaces — call members on them, never call the namespace itself.

### `$util`

```
$util
```

Runtime helper + reactive-environment namespace: data helpers ($util.format/.sum/.range/.groupBy…), formatting ($util.slugify/.truncate/.initials/.currency/.percent/.bytes/.relativeTime), misc ($util.copy — async, resolves true on real success —/.sleep/.uuid/.debounceFn/.throttleFn — leading+trailing), styling ($util.style.cx/.gradient/.alpha/.clamp/.token/.toStyle), validators ($util.rules.required/.email/.url/.min/.max/.minLength/.maxLength/.pattern/.oneOf/.matches/.custom/.asyncCustom + .validate/.validateAll), computed ($util.derived(fn)), hooks ($util.onError/.onNavigate/.onRequest/.onResponse/.invalidate), reactive env ($util.scroll/.viewport/.breakpoint/.media/.mouse/.url incl. .url.setQuery/.removeQuery), device ($util.vibrate/.share/.readClipboard/.geolocate/.isOnline/.deviceType/.nativeShell/.isNativeApp), and platform ($util.worker/.registerServiceWorker/.webManifest).

### `$storage`

```
$storage
```

Persistent storage namespace ($storage.local, $storage.session, …).

### `$console`

```
$console
```

Console namespace ($console.log, $console.warn, …).

### `$toast`

```
$toast
```

Imperative toasts: $toast.show/.success/.error/.dismiss; reactive .items.

### `$dom`

```
$dom
```

Managed DOM-observer namespace: $dom.onResize(node, cb) / .onIntersect(node, cb, opts?) / .onMutation(node, cb, opts?) (auto-disposed on replan) and .measure(node) → { rect, scroll, viewport }. Pair with Mount/OnMount node refs.
