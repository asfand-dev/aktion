# Helpers

8 components. [← back to the catalogue index](./index.md)

## When to use what

These are the library's own authoring notes — they encode the intended choice
between similar components, which the prop tables below cannot express.

- `Async(resource, { loading:, error:, empty:, data: })` switches an `$http({...})` resource on its `state` field (`empty` shows for `null`/empty-array data).
- `Show(when, { fallback?, children })` is sugar over `if (expr) { children } else { fallback }`.
- `Portal(target?, children)` renders into a different DOM subtree (defaults to `document.body`).
- `Redirect(path)` is a router-aware component — see Routing.
- `Lazy(loader, fallback?)` defers rendering until the async `loader` resolves, showing `fallback` while pending (a synchronous loader value renders immediately).
- `ErrorBoundary(fallback?, onError?, children)` catches rendering errors thrown by descendants.

## Reference

### Async

```
Async(resource, loading?, error?, empty?, data?, retry?)
```

Render `loading`, `error`, `empty`, or `data` slot based on an `$http({...})` resource's state. A value that is not a resource (a plain array or object) is treated as already-resolved data. Pass `retry` to add a Retry button to the error branch. State transitions are announced to screen readers.

| prop | type / values | required | notes |
| --- | --- | --- | --- |
| `resource` | `any` | **yes** |  |
| `loading` | `Node` | no |  |
| `error` | `Node` | no |  |
| `empty` | `Node` | no |  |
| `data` | `Node` | no |  |
| `retry` | `callable` | no | Called when the user presses Retry in the error branch (re-run the request) |

### Redirect

```
Redirect(path, replace?)
```

Navigate to `path` and unmount the rest of the subtree. Replaces the current history entry by default (guard semantics — Back must not return to the route that redirected); pass `replace: false` to push one instead.

| prop | type / values | required | notes |
| --- | --- | --- | --- |
| `path` | `string` | **yes** |  |
| `replace` | `boolean` | no | Replace the current history entry (default true) |

### Lazy

```
Lazy(loader, fallback?, children?, error?, onError?, retry?)
```

Defer rendering until an async `loader` resolves: show `fallback` while pending, then render the resolved value (or `children`). If the loader rejects, the `error` slot renders and `onError(err)` fires; `retry` adds a Retry button that runs the loader again. A synchronous loader value renders immediately.

| prop | type / values | required | notes |
| --- | --- | --- | --- |
| `loader` | `any` | **yes** |  |
| `fallback` | `Node` | no |  |
| `children` | `Node[]` | no |  |
| `error` | `Node` | no | Rendered when the loader rejects (defaults to the fallback) |
| `onError` | `callable` | no | (err) => … fired once when the loader rejects |
| `retry` | `callable` | no | Called after the built-in Retry button re-runs the loader |

### ErrorBoundary

```
ErrorBoundary(fallback?, onError?, showDetails?, onRetry?, children)
```

Render a fallback subtree when rendering children fails. Pass a `fallback` node (or omit it for a built-in friendly error card, which shows a Retry button when `onRetry` is set); `onError(err)` fires with the error. Set `showDetails=true` to reveal the message inline (great in dev).

| prop | type / values | required | notes |
| --- | --- | --- | --- |
| `fallback` | `Node` | no |  |

| `onRetry` | `callable` | no | Called when the user presses Retry on the built-in error card |
| `children` | `Node[]` | **yes** |  |

### FocusTrap

```
FocusTrap(child, active?, restoreFocus?, onEscape?, autoFocus?)
```

Confines keyboard focus to its subtree while `active` (default true) — Tab from the last focusable wraps to the first and vice-versa. Use inside modals, drawers, and command palettes. Auto-focuses the first focusable when it opens (`autoFocus: false` to opt out, or a CSS selector to pick the control), returns focus to whatever opened it on close (`restoreFocus: false` to opt out), and calls `onEscape` on the Escape key.

| prop | type / values | required | notes |
| --- | --- | --- | --- |
| `child` | `Node` | **yes** |  |
| `active` | `boolean` | no |  |
| `restoreFocus` | `boolean` | no | Return focus to the element that opened the trap when it closes (default true) |
| `onEscape` | `callable` | no | Called when Escape is pressed inside the trap — wire it to close the dialog/drawer |
| `autoFocus` | `boolean | string` | no | `false` to skip the initial focus, or a CSS selector inside the trap to focus instead of the first control (e.g. "[data-cancel]") |
